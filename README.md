# perms.io Homebrew tap

Homebrew casks for [perms.io](https://perms.io) tools.

```sh
brew install perms-io/tap/permio
```

| Cask | Description |
| --- | --- |
| `permio` | Command-line interface for perms.io permissions ([docs](https://docs.perms.io)) |

Casks in `Casks/` are generated by GoReleaser when a release is published. Don't edit them by hand.
